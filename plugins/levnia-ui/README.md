# levnia-ui

React/Next.js back-office UI design guidance (fleet-ui): token contract, component recipes, workspace shell, page archetypes, and optional finance, map and workflow modules.

## Skills

- `levnia-ui:fleet-ui` — 結構統一、皮膚自訂的 React/Next.js 後台 UI 設計指南——token 契約、元件配方、工作區外殼、頁面原型，與金融/地圖/流程選配模組。

## Use

Install via the [levnia/skills](../../) marketplace; Claude applies each skill
automatically when its trigger matches, or invoke one explicitly as `/levnia-ui:<skill>`.

```
/plugin marketplace add levnia/skills
/plugin install levnia-ui@levnia-skills
```

# start-ts-by

A Claude Code plugin that teaches Claude to scaffold new projects with the
[`start-ts-by`](https://www.npmjs.com/package/start-ts-by) CLI — create a
codebase from a git repository template (GitHub shorthand, branch + subdir,
SSH/HTTPS URLs) or a local folder, with file filtering, package renaming, and
post-create commands handled for you.

## Use

Install via the [venvia/skills](../../) marketplace, then ask Claude Code
things like *"scaffold a new project from user/repo"* or *"bootstrap a project
from this template"*. Claude runs `npx start-ts-by` with the right flags.
